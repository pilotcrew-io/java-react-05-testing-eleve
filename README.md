# Fullstack · Une chaîne de tests qui détecte les régressions — élève

**4 h 30 · Java / React / Qualité · PilotCrew.** Relier chaque risque à un test utile, automatiser le parcours local et démontrer deux régressions réellement détectées.

Le lab renforce les tests déjà écrits. Il ne demande pas de reconstruire l’application ni de multiplier des tests identiques pour augmenter un compteur.

Ce support contient les tutoriels, mémos et espaces de réponse. Créer le code demandé dans `backend/` et `frontend/` ; le corrigé est privé et séparé. Les six séances forment un fil rouge progressif de **27 heures**, sans promesse de niveau senior.

## Préparer la séance

Avant cette séance, importer votre réalisation validée de `java-react-04-webhooks-eleve` dans votre nouvelle copie `java-react-05-testing-eleve`. Reprendre backend/, frontend/ et scripts/ lorsqu’ils existent, ainsi que leurs configurations et lockfiles. Exclure .git/, target/, node_modules/, dist/, caches et sorties privées. Garder les documents de ce nouvel atelier. Noter le commit de provenance et exécuter les contrôles disponibles avant le début des 270 minutes.
